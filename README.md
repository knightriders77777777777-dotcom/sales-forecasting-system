AI-Based Sales Forecasting and Prediction System Using Machine Learning

Project Description

This project predicts future sales for the next 30 days using machine learning. It analyses historical sales data and displays predicted sales through a web dashboard.

Technologies Used

- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- Flask
- HTML and CSS

Project Features

- Historical sales data analysis
- Machine learning-based sales prediction
- Next 30 days sales forecasting
- Sales prediction graph
- Web-based dashboard
- CSV data and forecast results

Project Files

- "sales forecasting.py" – Main machine learning program
- "app.py" – Flask web application
- "sales_data.csv" – Historical sales data
- "forecast_results.csv" – Predicted sales results
- "sales_forecast.png" – Sales forecast graph

How to Run

1. Install the required Python libraries.
2. Run "python "sales forecasting.py"".
3. Run "python app.py".
4. Open "http://127.0.0.1:5000" in your browser.

Project Outcome

The system demonstrates how machine learning can be used to analyse sales data and predict future sales.
